# Data

## Source

**`hair_norwood_hamilton` v1**: Roboflow Universe, uploaded by *onuralpszr*, exported 2024-05-27.
<https://universe.roboflow.com/onuralpszr/hair_norwood_hamilton/dataset/1>
License: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)

5,783 JPEG images at 640×640 (stretch-resized, EXIF stripped by Roboflow), each labelled with one
Norwood–Hamilton stage 1–7. The vendor split is 5,029 train / 506 valid / 248 test images. The
paper explains why that split is **not** used for evaluation.

The images are not tracked in git. Download the dataset yourself.

## Expected layout

```
data/raw/
├── README.dataset.txt
├── README.roboflow.txt
├── train/_classes.csv + *.jpg
├── valid/_classes.csv + *.jpg
└── test/_classes.csv  + *.jpg
```

Either download the *Multi-Class Classification* zip from the page above and unzip it here, or use
the Roboflow API:

```python
from roboflow import Roboflow
rf = Roboflow(api_key="YOUR_KEY")
rf.workspace("onuralpszr").project("hair_norwood_hamilton").version(1).download("multiclass", location="data/raw")
```

## Released manifests (`splits/`)

| File | Rows | Contents |
|---|---|---|
| `split_manifest.csv` | 1,441 | Canonical dataset, one image per independent group, with `role` = `dev` (1,152) or `locked_test` (289). SHA-256 `dc94878c954130dc3aa7140dae1043de7f5660f27d41f910b7ec846a3f51e193` |
| `audit_manifest.csv` | 5,783 | Every vendor file with `vendor_split`, `stage`, `source_id`, `vendor_aug`, source `family`, `md5`, independent `group` and majority `group_stage` |

Both are regenerated by `python scripts/verify_audit.py`.

The lock is computed over the exact bytes of `split_manifest.csv`, which uses LF line endings.
`.gitattributes` keeps git from converting them. If you edit or re-save the file, the hash will no
longer match.

`group` is the union-find root index from the notebook's grouping step (§2.6). It is stable only for
this exact dataset version and file ordering.
