# Results: the reported run

These are the outputs of the full notebook run behind every number in the paper:
`QUICK_RUN = False`, seed 1337, 3 benchmark folds, 2,000 bootstrap resamples, TensorFlow 2.20,
scikit-learn 1.6.1, on a Colab T4, 2026-09-20. They were checked against the paper: the split lock,
Tables II and V–VII, the κ variants and the confidence-thresholding figures all match.

| File | Notebook § | Contents |
|---|---|---|
| `results_summary.json` | 14 | every headline number, the full config and the split lock |
| `benchmark_cv.csv` | 10 | pooled out-of-fold metrics for all baselines and deep models (Tables II–IV) |
| `test_predictions.csv` | 11 | 289 locked-test predictions: true and predicted stage, calibrated posteriors, nearest-dev Hamming distance |
| `residual_similarity_sensitivity.csv` | 11 | Table VI |
| `leakage_ablation.csv` | 13 | Table VII |
| `MODEL_CARD.md` | 14 | model card generated by the run (citation corrected to Guarrera et al.) |
| `figures/*.png` | 2–13 | all figures, including those used in the paper |

The split and audit manifests from this run are in [`../data/splits/`](../data/splits/). The
split manifest is byte-identical to this run's. The audit manifest drops the run's absolute Colab
paths.

Model weights (`*.weights.h5`, ~1.4 GB) are not included. To share the trained model, attach it to a
GitHub Release or host it on the Hugging Face Hub, and link it from the top-level README.
